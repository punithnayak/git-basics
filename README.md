A 10-minute hands-on for the **St Aloysius MediaWiki workshop**: make a repository, save versions, try ideas on two branches, and merge them back. Everything runs in your browser with Google Cloud Shell. Sign in with any Gmail account, nothing to install.

[![Open in Cloud Shell](https://gstatic.com/cloudssh/images/open-btn.svg)](https://shell.cloud.google.com/cloudshell/editor?cloudshell_git_repo=https://github.com/punithnayak/git-basics&cloudshell_tutorial=git-basics.md&show=ide%2Cterminal)

## What you will do

1. Tell Git who you are
2. Make a repository
3. Save point one
4. Change a file and see the difference
5. Branch one: `kannada`
6. Branch two: `places`
7. See both branches with `git log --graph`
8. Merge them back into `main`

The steps are in [git-basics.md](git-basics.md), which Cloud Shell opens as a tutorial panel.

| Git word | On Wikipedia |
|---|---|
| repository | the whole wiki |
| commit | one edit + summary |
| log | View history |
| branch | your sandbox |
| clone | downloading it all |
| push | Publish changes |
